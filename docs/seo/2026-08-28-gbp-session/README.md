## 5. B. GBP オーナー確認の手順（オーナーのスマホで操作）

1. D1 のアカウントで Google にログイン（Chrome / Google アプリ）
2. https://maps.google.com/?cid=18091006304497056848 を開き、「**ビジネス オーナーですか？**」をタップ
   - 表示されない場合: https://business.google.com/ → 「ビジネスを追加」→ 「愚問」を検索 → 既存リスティングを選ぶ（**新規作成しない**。重複リスティングになる）
3. 「管理を開始」→ 画面に従い、ビジネス名・カテゴリ・住所・電話（§6 の値）を確認
4. **確認方法を選ぶ**。2026 年時点の主流は **動画**。表示された選択肢の優先順:
   1. **動画**（即日〜数日）: 店の外観と看板 → 周辺（貝塚セルシーの表示）→ 店内 → スタッフしか入れない場所（厨房・レジ操作・鍵の開閉）を **1 本の動画で切らずに**撮る。店名が映る物（看板・メニュー・名刺）を必ず入れる。5 分以内
   2. **電話 / SMS**（即時）: 072-430-6038 にかかってくるコードを入力
   3. **メール**（即時）
   4. **ハガキ**（5〜14 日）: 届いたら business.google.com でコードを入力。**届くまでプロフィールを新規作成しない**
5. 確認が通ったら「ユーザー」→ 溝上 `mizogami.toshiki@bloom-l.com` を **管理者** で追加
6. 確認済み後に §6 を入力（審査待ちでも入力可）

### 分岐（うまくいかないとき）
- **「このビジネスは他のユーザーが管理しています」** → 「アクセス権をリクエスト」。現オーナー（想定: 過去の制作会社 or レストランボード経由）に通知が行き、**3 日**返答が無ければ Google 経由で自分で確認できる。誰が持っているかメールの一部が表示されるので控える
- **動画確認が「審査中」で止まる** → 通常 5 営業日以内。1 週間過ぎたら GBP ヘルプから問い合わせ
- **「ビジネスが停止されました」** → 再審査請求フォーム。名前にキーワードを足していないか、住所が実店舗か確認
- **同名の重複リスティングがある** → 確認後に「重複を報告」で統合
